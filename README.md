# Foleman Electricals

React, TypeScript, Vite and Tailwind website for Foleman Electricals.

## Run locally

Use Node.js 20 or later.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

The routes are `/`, `/about` and `/works`. The root `vercel.json` supports direct page navigation on Vercel.

## Enquiries

The form validates required fields and opens a prepared message in WhatsApp. The visitor must review and send it there. No submission is stored or emailed by this website. Phone, email and Instagram details live in `src/utils/brand.tsx`.

## Content

The founder portrait is the supplied original photograph, framed with CSS without altering it. Company services and contact details follow the supplied business card. Founding dates, qualifications, project counts and testimonials are omitted pending confirmation. Gallery locations, dates and specific project claims have been replaced by neutral labels; replace these with verified descriptions when available. Category assignments are inherited from the original repository and should also be checked with the company.

Dependency folders, build output and compiler caches are excluded from Git tracking.
